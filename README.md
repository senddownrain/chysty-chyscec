## Публикация

1. Содержимое этой папки (не сам ZIP) перенести в корень репозитория `senddownrain/chysty-chyscec`.
2. В GitHub: Settings → Pages → Source: Deploy from a branch → Branch: main, Folder: /(root) → Save.
3. До включения Pages разместить изменения в отдельной ветке/PR, если публикация ещё не разрешена.
4. Проверить доступность и функциональность из Беларуси без VPN.
5. Лишь после успешного тестирования указать `chyscec.rosica.by` как Custom domain и добавить отдельный CNAME на `senddownrain.github.io` в действующей DNS-зоне `rosica.by`.
6. Включить Enforce HTTPS после выпуска сертификата.

Для повторения проверок нужны Python 3, Pillow, Playwright, Chromium и Node.js:

```sh
python -m pip install Pillow playwright
python tests/check_static.py
for file in *.mjs; do node --check "$file" || exit; done
python -m http.server 8765 --directory ..
# В другом терминале:
SITE_TEST_URL=http://localhost:8765/chysty-chyscec/ python tests/check_browser.py
```

`CHROMIUM_PATH` позволяет указать путь к Chromium (по умолчанию `/usr/bin/chromium`). Для проверки корня домена запустите сервер с `--directory .` и задайте `SITE_TEST_URL=http://localhost:8765/`.

PDF сохраняется вне репозитория в `/tmp/chysty-chyscec-print.pdf`.

Настройки GitHub Pages и DNS не изменялись; workflow публикации и `CNAME` не добавлены. Проверки выполнены локально, доступность из Беларуси и выпуск HTTPS-сертификата проверяются после отдельно согласованного запуска.
